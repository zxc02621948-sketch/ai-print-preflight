AI 圖印刷前檢查與修復指南

先選圖片與輸出用途，評估海報、名片、帆布輸出風險，再依分步教學修復。

印刷邊界 本工具提供風險檢查與修復方向，不保證實際印刷結果；正式輸出仍需依印刷店規格、紙材、ICC Profile、CMYK 轉換與打樣結果確認。

手機提醒 手機適合先看分數與可印尺寸；需要放大、向量化、降噪、補出血或重排文字時，建議回到電腦操作。Upscayl 請優先用免費桌面版。

Delivery

轉檔交付建議

本工具不直接產生 .ai 或印刷級 PDF/X。新手送印時不要先丟一堆專業規格名詞；建議附上本工具報告，直接請印刷店協助確認能否代轉成可印格式，並詢問是否需要加收處理費。

新手交付話術

  • 「我不是設計專業，想請你們協助確認這張圖能不能印。」
  • 「如果需要轉成你們可印的格式，請協助代轉並告知費用。」
  • 「如果解析度、出血或裁切有問題，也請直接告訴我需要補哪裡。」

Illustrator

  • 適合 Logo、圖示、徽章、單頁海報。
  • 確認工作區尺寸、出血、連結圖片已嵌入。
  • File > Save As / Save a Copy，選 Adobe PDF；依店家要求選 PDF/X 預設。

InDesign

  • 適合多頁、排版、小字多的印刷物。
  • 先在文件設定建立出血，圖片與底色要延伸到出血外。
  • File > Export，選 Adobe PDF (Print)，Marks and Bleeds 勾 Crop Marks 與 Use Document Bleed Settings。

Acrobat Pro

  • 適合最後檢查，不適合當主要設計工具。
  • 用 Preflight 檢查 PDF/X、字型、色彩與影像解析度。
  • 若 Preflight 報錯，回 Illustrator / InDesign 修原檔再重新輸出。

Vector Guide

什麼是向量化？

向量化是把 PNG / JPG 這種由像素組成的點陣圖，改描成線條、節點與色塊。成功後的 Logo、圖示或徽章可以放很大，邊緣也不會因為像素不足而糊掉。但它是進階選項，不是送印必做；多數情況先提升解析度再輸出高解析 PNG / PDF 會更快。

適合考慮向量化

  • 邊界清楚、背景乾淨。
  • 色塊簡單，約 8 到 16 色內。
  • Logo、圖示、徽章、剪影或扁平符號。

不適合硬轉

  • 角色厚塗、照片、煙霧、光影很多。
  • 細碎漸層或材質會變成大量色塊。
  • 轉出來很髒或檔案很重時，改用高解析 PNG / PDF。
向量化後還需要修解析度嗎？

如果已成功轉成乾淨的純向量 SVG / PDF，該圖示本身通常不需要再修 DPI。若作品裡還有點陣背景、照片、材質，或最後仍要用 PNG 輸出，仍要回本工具檢查解析度。
